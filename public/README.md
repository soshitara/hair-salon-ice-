# ICE. HAIR SALON LP 再現版

## 開き方
ZIPを解凍し、`index.html`をブラウザで開いてください。インストールやビルドは不要です。HTML、CSS、JavaScriptと仮画像をすべて同梱しています。インターネット接続なしでも表示・アニメーションは動作します（外部リンクを除く）。

## 内容
- index.html：全セクション、本文、料金表、リンク
- styles.css：配色、レイアウト、700px以下のモバイル表示、アニメーション
- script.js：スクロールに応じた表示、準備中ボタンの案内
- assets/：差し替え可能なSVG仮画像9点

## 参照・再現範囲
参照：https://soshitara.my.canva.site/ice-20261031
確認日：2026年11月8日。ブラウザでデスクトップ幅とスマートフォン幅を確認。

アイボリー／チャコール／ゴールドの配色、セクション順、本文、料金表、カード、装飾枠、予約・アクセス・フッター構成を再現しました。スマートフォンでは画像とカードが縦に並びます。ナビゲーションは小さな横並びを維持します。

元ページの写真・地図は使用せず、すべて自作の仮画像に置き換えています。assetsのファイルを同名で差し替えるか、HTML/CSS内の画像パスを変更してください。地図は位置を正確に示すものではないイメージ画像です。クリックすると記載住所のGoogle マップ検索が開きます。

Canvaの内部レイアウト・専用フォント・表示エンジンは使用せず、一般的なHTML/CSSで近似しています。フォントは端末の日本語フォントで代替されるため改行や字形は異なります。モバイルの極端な不自然な改行は整えています。表示アニメーションは観察できたフェードと移動をCSSとIntersectionObserverで近似し、元の厳密な速度・順序までは一致保証しません。表示済み要素は再び隠れません。端末の「視差効果を減らす」設定ではアニメーションを無効化します。

予約ボタンは参照時点の「準備中」を維持しています。ヒーローのボタンは予約欄へ移動し、予約欄のボタンは準備中の案内を表示します。実際の予約送信やフォーム処理はありません。LINE・Instagramリンクは参照ページで確認した公開リンクです。電話番号は元ページの仮番号のまま記載し、発信リンクにはしていません。

## 公開前の差し替え
実写真、正確な地図、予約受付リンク、電話番号、営業時間・料金を確認してください。必要に応じてフッター表記も編集できます。外部ライブラリ、アクセス解析、Cookie保存は使用していません。
